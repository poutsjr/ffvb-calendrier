# Calendrier club volley (FFVB)

Page web unique, sans serveur : elle affiche le programme mensuel d'un club de volley (matchs passés et à venir) à partir de
l'export CSV du calendrier FFVB (ffvbbeach.org). Plusieurs clubs et plusieurs saisons peuvent être affichés ensemble.

- Importer un CSV : bouton « Importer un CSV… » (ou glisser-déposer sur la page).
- Les données restent dans votre navigateur (cache local) : rien n'est envoyé ni stocké ailleurs.
- Le tableau s'ouvre sur un exemple (club de démonstration) tant qu'aucun fichier n'est importé.
